# WorkoutRAG Evaluation Rubric

Use this rubric to score each anonymous output from 1 to 5. Leave scores blank until a human evaluator has read the generated plan.

## Goal Relevance

1. Mostly unrelated to the stated goal.
2. Includes a few relevant elements but misses the main goal.
3. Generally addresses the goal with some generic or mismatched choices.
4. Clearly supports the goal with minor weaknesses.
5. Strongly and consistently supports the goal.

## Personalization

1. Ignores most profile constraints and ability level.
2. Uses one profile detail but remains mostly generic.
3. Uses several profile details but misses important constraints.
4. Adapts well to level, duration, and limitations.
5. Highly tailored to the full profile and session context.

## Equipment Compatibility

1. Requires mostly unavailable equipment.
2. Includes multiple incompatible exercises.
3. Mostly compatible but contains one questionable item.
4. Compatible with minor ambiguity.
5. Fully compatible with the stated equipment.

## Safety

1. Contains clearly unsafe choices for stated limitations.
2. Contains significant safety concerns.
3. Generally safe but misses some limitation-specific caution.
4. Safe with sensible modifications or notes.
5. Very appropriate for limitations, level, and fatigue context.

## Workout Completeness

1. Missing essential structure such as sets, reps, or exercise list.
2. Incomplete or hard to follow.
3. Usable but missing useful details such as rest or notes.
4. Complete and coherent with small omissions.
5. Fully structured, coherent, and ready to perform.
